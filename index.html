Understand password strength from the inside out.

Black Pass is a command-line password guesser. Type in a password and watch how a dictionary attack and a brute-force search try to find it — a hands-on way to learn why length and unpredictability matter.

How it works

Two strategies, one lesson

01

Dictionary attack

It first tests the 184,388 most common real-world passwords from the phpbb.txt breach list. Weak or reused passwords are found almost instantly.

02

Brute force

If the wordlist misses, it generates every possible character combination from length one through ten — distributed across all of your CPU cores at once.

Black Pass only ever guesses the password you enter yourself. It is an educational tool, not an attack tool.

Performance

Multiprocessing vs. threads

The default distributes work across every CPU core. The thred commands use threads instead — but Python's Global Interpreter Lock (GIL) permits only one thread to execute at a time, so they effectively share a single core.

Multiprocessingall cores
0.16s
Threadssingle core
0.39s

Measured on the same search · lower is better

In thread mode the reported guess count also rises sharply — threads keep working while the “found it” signal propagates. The result is correct, but slower. For speed, use black_pass.

Usage

Running it manually

python3 index.py                   # brute force (all cores)
python3 index.py print             # print every guess
python3 index.py dict              # wordlist first
python3 index.py dict print        # wordlist + print
python3 index.py thread            # threads instead of cores
python3 index.py thread dict print # flags combine in any order

Requires Python 3. Both files must be located in the same directory.
